# QuadLoom 0.4.3 — Detect Settings

**Not released on its own.** 0.4.3 was built and tested but not published; its changes ship in [0.4.6](0.4.6.md), the first public release after 0.4.0. The artifact named below was never distributed.

## What is new (decision [0025](../decisions/0025-detect-settings.md))

- **Detect Settings**, a button under Sharp Edges in the main panel. It reads the active mesh's crease lines (no remesh, a fraction of a second on most meshes) and changes nothing.
- **A Detection box** with what it found: the kind of model, its crease lines, how many are long or sharp, the scraps, and the Sharp Edges and Ignore Faint Creases it suggests beside the values you have now, with a line of why.
- **Apply Suggested Settings** sets those two settings, as one undo step.
- If you select another object, edit the mesh or change the angle, the box says to detect again and Apply is disabled.
- A patch whose quads would cut through the model keeps its triangles instead (SpecularSilkPouf with faint creases ignored: 9.4% off its input to 0.55%).
- The add-on's API version is 11: restart Blender after installing over an older version.

## The kinds, and what is suggested

| Kind | Read from | Suggestion |
|---|---|---|
| Hard Surface | nearly all the crease in long or sharp lines | Sharp Edges on, every crease kept |
| Sculpt With Creases | long or sharp creases, and scraps beside them | Ignore Faint Creases 9 |
| Surface Detail Only | scraps and nothing else | none |
| Smooth Surface | next to no crease | none |

Sharp Edges off is never suggested: it gives up the hard edges.

## How good the suggestion is

Each of the 70 benchmark models with its detected settings, against the defaults:

- 42 models are not changed (32 hard surface, 6 surface detail only, 4 smooth).
- Of the 28 it changes, quad shape (mean scaled Jacobian) is **better on 19 and worse on 9**; the worst 5% of quads are better by 0.03 on average.
- Distance from the input is a little worse on 17 of the 28 and better on 10. One is a clear step back: a pig's curly tail, thinner than a quad, goes from 0.95% to 2.0% off.

So it is a suggestion to look at, with its numbers, not a setting applied for you.

## Validation

Rust tests with all features and default (14 + 336 + 22 / 19, 6 ignored), both clippy configurations, `cargo fmt --check`, 126 Python tests and 50 of 50 Blender scenarios on the dev build. The production zip then passed eleven Blender smoke scenarios: cube_passthrough, detect_suggests_settings_and_applies_them, attributes_are_kept, quick_rerun_reuses_the_layout, scene_switch_drops_completed_job, malformed_result_is_rejected, undo_redo_result_is_safe, gui_modal_remesh, target_count_mode_and_quick_rerun, target_count_presets_preserve_request, remesh_makes_quads.

The benchmark through the add-on was not re-run for this version: at default settings its results differ from 0.4.2's on one model of 70 ([0.4.2's report](../../benchmark/reports/20261127-q042-default/README.md)).
