# QuadLoom 0.3.0 — OOM hardening

This release covers OOM hardening. It includes the attribute-transfer feature
committed since 0.2.0, which had not yet received a release build.

- Remeshing and native attribute mapping run in an isolated memory-limited worker.
- The default worker budget is 2048 MiB (System → Worker Memory).
- OOM/abort, stalled cancellation, scene changes and malformed geometry fail safely.
- UVs, materials, vertex groups, colours and the rig are transferred when enabled.
- Existing Density behavior and remeshing algorithms are unchanged. Target quad
  count is reserved for 0.4.0.

Blender's own modifier evaluation and mesh allocations remain in-process;
admission checks cannot guarantee against system-wide exhaustion. End-to-end
overhead and exact output parity on larger real assets remain to be measured.
See decisions 0019 and 0021 for details and remaining limits.

Tag: `v0.3.0`. The 0.3.0 source is available at that tag.
Validation passed on Windows / Blender 5.2.2: both Rust configurations

runtime version and fault-injection rejection checks plus seven representative
Blender scenarios, including attributes, cache, scene safety, undo and GUI remesh.
