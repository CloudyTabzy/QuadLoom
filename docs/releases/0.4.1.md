# QuadLoom 0.4.1 — Better quads, and the worker fix

**Not released on its own.** 0.4.1 was built and tested but not published; its changes ship in [0.4.6](0.4.6.md), the first public release after 0.4.0. The artifact named below was never distributed.

## What changed

- **The quad stage is rebuilt** (decision [0023](../decisions/0023-quad-geometry.md)): pattern points are placed by solving, a new relaxer keeps thin parts and lets feature vertices slide, sides are cut wherever the layout branches, long uneven patches get a bridged grid in place of a fan, and a feature that stops an edge short of a boundary is cut through.
- **The worker no longer fails on `progress.json`** (decision [0021](../decisions/0021-crash-containment.md), addendum). Released 0.4.0 failed about one run in six on Windows.
- The run report gains `bridge_patches`. The settings and `API_VERSION` are unchanged.

## Known limits

Decision 0023's "Still open" list: tiny patches where features are denser than the quads, 131 patches kept as triangles over the 70 models, thin features at the default size, an inverted quad in 46 of 70 results, and quantization time on many-patch models.
